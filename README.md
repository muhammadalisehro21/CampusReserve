# CampusReserve
A Smart Campus Resource Reservation Engine built in Java with conflict prevention logic.

## 🚀 Features
- **Conflict Prevention:** Checks real-time availability to avoid double booking.
- **Priority Management:** Handles reservations based on assigned priority levels.
- **Interactive Console Menu:** Simple CLI interface for users to book and view reservations.

## 🛠️ Technologies Used
- **Language:** Java (JDK 8 or higher)
- **Data Structures:** ArrayList, Custom Classes

## 💻 How to Run
1. Clone or download this repository.
2. Open the project in your IDE (IntelliJ IDEA, Eclipse, etc.).
3. Run `Main.java` to launch the reservation system.
